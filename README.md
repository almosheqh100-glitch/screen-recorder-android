# تطبيق تسجيل الشاشة

مشروع أندرويد مستقل مبني من فكرة وكود الإضافة المرفقة. استُبدلت واجهة Toga/Python بواجهة Java عربية لتكون الحزمة مشروعًا كاملًا. النسخة الأصلية محفوظة في original-addon.zip.

## الحصول على APK
1. افتح تبويب Actions في GitHub.
2. اختر Build APK ثم أحدث تشغيل ناجح.
3. نزّل screen-recorder-apk من Artifacts وفك الضغط.
4. انقل app-debug.apk إلى الهاتف وثبّته بعد السماح بالتثبيت من هذا المصدر.

يعمل على Android 10 فأحدث. يطلب موافقة تسجيل الشاشة لكل جلسة. صوت الميكروفون اختياري؛ صوت التطبيقات الداخلي غير مدعوم. الزر العائم اختياري، ويمكن الإيقاف من الإشعار أو التطبيق. تُحفظ الفيديوهات في Movies/ScreenRecords وتظهر في المعرض. عند تدوير الهاتف قد تظهر حواف حول الفيديو لأن أبعاد التسجيل ثابتة أثناء الجلسة.

## البناء
Java 17، Gradle 8.11.1، Android SDK 35. شغّل gradle assembleDebug. لا توجد حاجة إلى Briefcase.

## حالة التحقق
المشروع مجهز للبناء؛ نتيجة التصريف يؤكدها تشغيل GitHub Actions. لم يُختبر تسجيل الشاشة على جهاز حقيقي بعد. APK الناتج نسخة debug للتجربة، وليس إصدار متجر. قد يلزم حذف نسخة تجريبية سابقة قبل تثبيت بناء جديد بسبب اختلاف مفتاح التوقيع بين بيئات البناء. للإصدار النهائي يلزم مفتاح توقيع ثابت يحتفظ به مالك التطبيق.
